# ED II - Practice 2: Binary Trees

Course: Estructuras de Datos II
University: Universidad de Huelva
Year: 2025-2026

## 📄 Description
Binary tree exercises in C++ using the Arbin iterator-based API.
Covers recursive operations including leaf counting, symmetric tree
construction, zigzag traversal, and root-to-leaf word printing.

- Language: C++
- IDE: Code::Blocks
